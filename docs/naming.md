2026-11-22 に、識別子も `banmen` に改めると決めた。基盤とつながらないものから先に改め、Cloudflare と GitHub の資源とつながるものは、人が行う手順と合わせて #1416 で改める。

Google Cloud の OAuth の同意画面のアプリ名（`operations.md` の「Google のログイン」）は、利用者がログインで目にする表示なので `Banmen` にそろえる。本番と開発用の設定は、人が Google Cloud コンソールで改める。

利用規約とプライバシーポリシーの本文の名前の差し替えは、版を上げない直しとして扱う（2026-11-22 に人が決めた）。サービスの中身と約束は変わらないため。

## Banmen にした理由

- 「スクラムギルド」は、スクラムとゲームの世界観を伝えられる一方、日常の会話では少し長く、略称も定めにくかった。Backlog、Notion、Linear のように、チームが正式名のまま短く呼べる名前を目指した。
- 「朝会で盤面を見よう」が、そのまま製品の呼び名と使い方になる。タスクが並ぶカンバンボードを全員で見て、仕事がどこで止まっているか、次に何を引き取るかを決める。
- 「盤面」にはゲームの盤の意味もあるが、ゲームの要素は外したので（#1430）、ここでの意味は朝会で見るタスクの盤面だけにする。

名前からは「Scrum」が外れ、スクラムの道具だと名前だけでは伝わらない。README の一行目と画面のスクラムの言葉で補う。

## Scrum Guild にした理由（2026-10-24、改める前）

- 「Scrum」が入っていて、スクラムでチームのタスクを回す道具だと名前で伝わる。
- 「Guild」は、デザインの土台にした「ギルドの帳簿」の世界観と、ゲームの言葉の側に合う。スクラムの言葉とゲームの言葉の両方を持つこの道具の性格を、名前の前後で表す。
- 「Quest」を使わず、ABI の「SCRUM QUEST」とは後ろの語で見分けられる。「Scrum」が重なるので、検索で並ぶことは受け入れる。

名前からは記録（完了の記録、請求の根拠）の役目が読み取れない。README の一行目で補う。
