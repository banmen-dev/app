## 4テーマの見た目と言葉

保存した本番 build を同じ使い捨て D1・公開 seed で比較した。simple、simple_light、simple_dark、modern の4テーマで、API の本人のテーマと localStorage をそろえ、フォント完了と network idle の後に撮った。回線は制限せず、速度の計測に混ぜない。版番号の領域を除いた1280×880pxを比較した。

4テーマとも差は左上のマークの227画素だけで、RGB各成分の最大差は1（0〜255）。PNG/WebP の半透明色のデコード時の丸めによる差で、文字・枠・配置の画素は一致した。Python で比較した元PNGと可逆WebPのRGBAは全バイト一致する。ブラウザ側の回帰テストは透過の一致と、白い下地への合成後の色差1以内を確かめる。

生成した12個のフォントについて、元の対応文字がすべて残り、400・500・600・700・900の5段階、合計5,095通りの文字×太さで分解した横書き輪郭と送り幅が一致した。`e2e/fonts.test.ts` の既存の書体・太さ・CSP検査もCIで継続する。
