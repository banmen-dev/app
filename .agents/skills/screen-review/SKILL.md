# screen-review（Codex）

`AGENTS.md` と [共通の読み替え](../README.md) を読み、[共通の手順](../../../docs/agent-workflows/screen-review.md) に従って対象を決め、撮影、採点、修正、引き渡しを行う。

進行役は [採点役の定義](../../../.claude/agents/screen-critic.md) の本文を採点指示に使う。会話履歴を引き継がない Codex のサブエージェントを各周で1体起動し、採点指示と、対の画像、演出の連続コマ、撮影時の `design-rules.md`（`docs/design.md` の2節の抜粋）、テキストの除外一覧の絶対パスだけを渡す。画像は周のディレクトリでなく、撮影の完了の表示に並ぶ絶対パスを1枚ずつ渡す。資料だけを読むよう指示する。これは Codex での運用上の制限で、実行基盤によるツールやファイルアクセスの制限とは区別する。

使える独立した採点役がいない場合は未実施とし、撮影できた資料と未実施の理由を引き渡す。
