# issue-create（Codex）

最初に `AGENTS.md` と [共通の読み替え](../README.md) を読む。
[共有する手順](../../../.claude/skills/issue-create/SKILL.md) を読み、次の Codex 向けの扱いを優先して進める。

Issue の作成・更新は承認範囲で行う。対案を比較するときは原本の独立性を守り、人の答えと自分の前提を分ける。
論点を人と詰めるときは [詰める手順](../../../.claude/skills/issue-create/refine.md) に従う。`rename-session` は省く。ラベル更新は承認範囲で行い、承認が無ければ `status:refining` を付けずに論点整理を先に進める。
